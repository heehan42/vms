# Spec Delta

## MODIFIED Requirements

### Requirement: 송신 시작
서버는 동영상이 지정된 세션의 DTLS가 완료되면, 그 세션에 지정된 동영상의 첫 프레임부터 송신을 시작해야 한다(SHALL). 동영상이 지정되지 않은 세션에는 아무것도 보내지 않는다. 패킷은 그 세션의 nominated pair의 서버 주소에서 브라우저 주소로 보낸다. 송신을 시작할 때 세션, 동영상 ID, SSRC, payload type을 로그에 한 번 남긴다. 세션마다 송신 위치를 따로 가지므로, 늦게 연결한 세션도 첫 프레임부터 받는다.

#### Scenario: Chrome에서 영상 재생
- **WHEN** README의 명령으로 만든 파일이 든 디렉터리를 지정해 서버를 실행하고, Windows Chrome의 연결 확인 페이지에서 그 파일을 골라 연결한다
- **THEN** 페이지의 `<video>`에 테스트 영상이 움직이며 표시된다

#### Scenario: 두 세션
- **WHEN** 첫 탭이 연결되어 몇 초 재생된 뒤 두 번째 탭이 같은 동영상으로 연결한다
- **THEN** 두 번째 탭의 첫 패킷은 첫 프레임의 것이며, 두 탭 모두 영상이 표시된다

#### Scenario: 세션마다 다른 동영상
- **WHEN** 두 탭이 서로 다른 동영상을 골라 연결한다
- **THEN** 각 탭에는 자신이 고른 동영상이 표시되고, 서버 로그의 송신 시작 줄에 세션별 동영상 ID가 나온다
